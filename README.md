# Фаза

Сметы на электромонтаж для частных мастеров. Мастер вводит объёмы и цены на замере, проверяет расчёт и отправляет заказчику ссылку. Заказчик открывает смету без регистрации и может сохранить PDF через меню печати.

## Попробовать на компьютере

Понадобится Node.js 22.13+ или 24 LTS. Приложение использует встроенный SQLite и запускается без установки пакетов.

```sh
npm start
```

Откройте [редактор](http://127.0.0.1:3000/) и [пример документа для заказчика](http://127.0.0.1:3000/q/example). Начальные расценки иллюстрируют работу редактора. Замените их прайсом мастера. Черновик хранится в браузере, кабинеты, прайсы, заказы и опубликованные сметы — в SQLite. Ссылки с локального адреса работают только на том же компьютере.

## Платный пилот

Первая смета по ссылке бесплатна. Стартовая цена «Мастера» — **990 ₽ за 30 дней**. В первое подключение входит перенос одного прайса и совместная подготовка одной сметы. Это ценовая гипотеза для первых продаж. Публикация и архив автоматизированы, сопровождение и расчёт с клиентом выполняет владелец.

1. Мастер выбирает «Тариф» → «Оформить заказ». Сервис создаёт заказ и открывает Telegram владельца с номером заказа по кнопке пользователя.
2. Владелец сообщает клиенту условия и присылает свою платёжную ссылку с согласованной суммой. Проверьте поступление у своего платёжного провайдера и оформите расчёт в принятом у вас порядке.
3. После фактического получения 990 ₽ активируйте оплаченный заказ. Повторная активация того же номера безопасна. Продление добавляет 30 дней к текущему сроку или к сегодняшней дате, если доступ истёк.

```sh
npm run orders
npm run activate -- FZ-НОМЕР
```

На VPS используйте команды внутри контейнера с боевой базой:

```sh
docker compose exec app node billing.mjs list
docker compose exec app node billing.mjs activate FZ-НОМЕР
```

4. Мастер нажимает «Проверить доступ». Для переноса прайса скопируйте три столбца без заголовков из Excel: работа, единица, цена. В кабинете откройте «Прайс-лист» → «Импорт из таблицы». Публикуемые ссылки фиксируют цены на момент отправки и доступны после окончания подписки. Ссылку может открыть любой её получатель.

## Первая продажа до готовности VPS

[Скачать демонстрационную смету в PDF](output/pdf/faza-example.pdf) для показа в Telegram.

Покажите пример сметы знакомому электромонтажнику на созвоне. Спросите, есть ли объект, который он считает сейчас. Если есть, предложите перенести 5–10 строк его прайса, добавить объёмы и собрать первую смету вместе.

> Пришли прайс и объёмы по одному объекту. Сегодня покажу, как будет выглядеть смета для заказчика. За 990 ₽ перенесу твой прайс, помогу с первой сметой и подключу кабинет на 30 дней после запуска. Подойдёт для ближайшего замера?

До запуска публичного адреса смету можно передать PDF: опубликуйте её локально, откройте страницу заказчика и выберите «Печать / PDF». Для учёта предзаказа запишите номер и активируйте доступ в рабочей базе при запуске. Если уже ведёте локальные кабинеты, перенесите их базу на VPS до открытия сервиса для новых клиентов.

## Развёртывание на VPS

1. Направьте DNS-запись домена на IP VPS, откройте входящие TCP 80/443. Установите Docker с Compose.
2. Склонируйте репозиторий, войдите в каталог и создайте файл `.env`. Замените пример домена своим.

```dotenv
DOMAIN=smeta.example.ru
SALES_TELEGRAM=FoolyQ
```

3. Запустите приложение. Caddy запросит сертификат для домена. Порт приложения доступен внутри сети Compose.

```sh
docker compose up -d --build
docker compose logs --tail=50 proxy app
```

4. Откройте домен по HTTPS. В новом кабинете опубликуйте первую смету, проверьте её в приватном окне и перейдите к оформлению заказа. Перед выдачей доступа клиентам проверьте, что Telegram открывает нужный аккаунт.

Данные сохраняются в томе `estimates`. Для резервной копии остановите только сервис приложения, скопируйте содержимое каталога `/data` из его контейнера и запустите сервис. При переносе локальной базы остановите локальный сервер перед копированием файлов SQLite. Поместите их в пустой том до первого рабочего запуска и дайте пользователю `node` контейнера права на чтение и запись. Храните копии базы вне публичного репозитория.
